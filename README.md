# Beast3 Executive Administration

A governance, policy, and operational control platform for the Executive Administration Division of Beast3.

## Overview

This repository provides the foundation for:
- executive governance records
- policy and directive management
- division coordination and operational oversight
- strategic planning and audit visibility

## Project Goals

- Centralize governance operations for Beast3
- Create a clear executive workflow for policy approval and enforcement
- Track directives, performance, and operational health
- Support division-level coordination across the overall Beast3 structure

## Structure

- `docs/` — governance and policy documentation
- `src/core/` — domain logic and executive workflows
- `src/api/` — API endpoints for executive operations
- `src/app/` — Next.js application screens
- `src/lib/` — shared configuration and data utilities
- `src/types/` — domain TypeScript models

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
